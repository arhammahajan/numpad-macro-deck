# keyboard-streamdeck
If you've ever wanted a stream deck but dont wanna spend 200$ here's an alternative which will cost you 10$ and a bit of patience. Using python, autohotkey and luamacros, (all of which being open source themselves) you can use any generic usb keyboard or numberpad as a streamdeck. 

It wont do exactly or as good as what the stream deck is capable of but for less than 1/10th the price it's quite worth it.
